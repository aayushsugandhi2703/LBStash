01
Create your ingest token

02
Open Shortcuts and start an automation
On your iPhone open the Shortcuts app, then go through these screens.
Shortcuts › Automation › New Automation › Message
03
Set the trigger: Message Contains
Make one automation per word. Your bank may phrase things differently, so check a real message and add that word too.
debited credited
Never trigger on every message from the bank. Banks also text OTPs, and an OTP must never leave your phone.
04
Add the action: Get Contents of URL
Fill it in exactly like this. First add a Dictionary action with the three fields below, then this action with Request Body set to JSON and that Dictionary as its value. Your shortcut should have only these two actions: fewer steps run more reliably on a locked phone.
URLhttps://your-server/ingest/message
METHODPOST
HEADERAuthorization: Bearer ledg_live_••••••••
BODYtext = Shortcut Input (the message)
receivedAt = Current Date (fallback time only)
nonce = Random Number + Current Date
05
Run it immediately, silently
Pick Run Immediately (not Ask Before Running) and turn Notify When Run off. If your iOS offers a run-while-locked setting for the shortcut, turn it on. Tap Done. Repeat for the second word.
iPhone may run it late while locked. That is fine: each payment is saved at the time written in the bank message, and a balance check later catches anything that never arrives.

WHAT TELEGRAM NEVER GETS
No amount, no payee, no balance, no account number, no bank name, no UPI ID, no original message. Each message only says that money went out or came in, and when.
Show a Reveal buttonTap it to see the amount and payee for 30 seconds. While visible, those details pass through Telegram. Off means Telegram never sees any bank detail.
